# Pofu Code Studio 1.7.0

Controle do computador, visão em imagens do projeto, pesquisa web com leitura de páginas e medidores no compositor.

- `capture_screen` e `computer_action`: o agente vê o monitor real e usa mouse e teclado no Windows, conferindo cada ação por um novo print. Desligado por padrão (**Configurações → Ajustes → Ferramentas → Controle do computador**); exige modelo com visão. No modo Manual cada ação pede aprovação; **Parar** ou **Ctrl+Alt+Esc** interrompem.
- `view_image` abre imagens do projeto e envia os pixels ao modelo. A visão também é detectada pelas modalidades de entrada anunciadas, incluindo o llama.cpp.
- Pesquisa web lê o conteúdo das páginas encontradas, com provedor de reserva.
- Contexto e cota viraram anéis discretos abaixo da caixa de mensagem, ao lado do modelo; amarelo a partir de 70%, vermelho a partir de 90%. Clique na cota para ver o consumo.
- Falha transitória espera 10 segundos antes de tentar de novo, com contagem regressiva e cancelamento.
- Controle remoto com botão único **Ligar/Desligar** na lateral, mostrando conexão e tempo até reconectar.

Instaladores para Windows (`.exe`), Ubuntu/Debian (`.deb`) e Fedora (`.rpm`).
